# Eunice Reader · 产品介绍

> 用途：让美术/设计侧在不动代码的前提下，准确理解「这是什么产品、给谁用、长什么样」，
> 以便产出一批**符合产品气质**的配图、插画、图标、宣传物料。
> 依据：本仓库源码（`src/`、`src-tauri/`）+ 实际构建产物 `dist/`，非市场宣传文案。
> 配套文档：[design-system-extract.md](design-system-extract.md)（可回溯的色值/尺寸规格表）。

---

## 一、一句话定位

**Eunice Reader 是一款面向 Windows 的 Markdown 阅读器 —— 以「浏览」为主、以「轻量编辑」为辅。**

它不是代码编辑器，也不是笔记软件。它服务的是一个非常具体的场景：

> 手里有一份别人发来的 `.md` —— 方案、提案、调研报告、周报 —— 想**舒服地读它**，
> 顺便把附件图片、表格、公式、图表都正确显示出来；偶尔要改两个字，也改得动。

这句话决定了产品的全部设计取向：**界面退到背景里，让文档本身当主角。**

---

## 二、给谁用：一个明确的「非程序员」立场

产品的目标用户是**读文档的人**，不是写代码的人。这一点在源码里有三处刻意声明：

| 位置 | 原文要点 |
|---|---|
| `src/styles/theme.css:7-9` | 刻意不用外部配色库（含 highlight.js 的 82 套代码主题）：「挑代码配色是程序员需求，不是文档需求」 |
| `src/ui/settings.js:13-15` | 设置面板里**没有**「代码配色」这一项：「不值得让读者去挑 82 套程序员配色」 |
| `src/lib/doc-themes.js:5-6` | 主题命名刻意避开任何「代码 / 终端 / 开发者」意象 |

**推论（对美术最要紧的一条）**：代码块在这款产品里不是主角，而是**纸张上的一个灰色方块**。
任何一张资产里都不该出现「深色 IDE 面板 + 霓虹语法高亮」这种程序员意象；
代码块的底色与边框必须和正文纸面同色系。

## 三、功能版图

### 3.1 阅读（核心能力）

打开文件即进入**阅读视图**，编辑器完全隐藏 —— 这是阅读器的本分。
`Ctrl+3` 或工具栏才切到编辑视图。

| 能力 | 实现 | 用户可感知的表现 |
|---|---|---|
| 完整 GFM 语法 | markdown-it 15 | 标题、粗体、删除线、列表、任务列表、表格（含对齐）、引用、代码块 |
| 表格对齐 | markdown-it 原生 | `:--` / `--:` 真的会左右对齐 |
| 任务列表 | markdown-it-task-lists | `- [x]` 渲染成真复选框，可勾选样式 |
| 脚注 | markdown-it-footnote | 文末脚注区 + 正文上标跳转 |
| Emoji | markdown-it-emoji（full） | `:rocket:` → 🚀 |
| 标题锚点 | markdown-it-anchor | 悬停标题浮现 `#`，可复制链接 |
| 提示块 | markdown-it-container | `:::tip` / `:::note` / `:::important` / `:::warning` / `:::caution` 五种，中文标签为 提示/说明/重要/注意/警告 |
| 数学公式 | @vscode/markdown-it-katex + KaTeX | 行内 `$...$`、块级 `$$...$$`（VSCode 同款插件） |
| 代码高亮 | highlight.js（common 子集） | 6 色克制着色，随主题走 |
| 图表 | mermaid 12 | ```mermaid 代码块渲染成真 SVG；**按需加载**，冷启动不背这个包袱 |
| 内嵌 HTML | markdown-it + DOMPurify | `<details>`、`<img>` 等可用，但必须过消毒 |
| Front Matter | 自研剥离（不用插件） | 文件头 YAML 被剥掉，正文正常渲染，且不残留一条 `---` 分隔线 |

**渲染后处理**（`src/markdown/enhance.js`）—— 这些是「读起来顺」的关键细节：

- **代码块**：右上角自动补**语言标签** + **复制按钮**（复制成功文案变「已复制」，1.6s 复原）
- **宽表格**：套一层横向滚动容器，窄窗口下不撑破布局
- **断图兜底**：图片加载失败不是碎图图标，而是斜纹占位 + 悬停显示失败路径
- **外链标记**：站外链接追加 `↗`，点开交给系统浏览器
- **相对路径解析**：文档里写 `![](./a.png)`，基于**文档自己所在目录**解析，而不是程序目录

### 3.2 大纲导航

`Ctrl+B` 唤出左侧大纲侧栏（**默认关闭**）。

- 从渲染后的 `h1`–`h6` 抽取，按层级缩进（1 级加粗、2/3/4+ 级逐级内缩）
- 滚动正文时用 `IntersectionObserver` **高亮当前所在章节**，左侧 2px 强调条 + 淡底
- 空文档时给一句「当前文档没有标题。」而不是空白

### 3.3 轻量编辑（三个视图）

| 视图 | 快捷键 | 说明 |
|---|---|---|
| 阅读 | `Ctrl+1` | 默认。只有文档，没有编辑器 |
| 分栏 | `Ctrl+2` | 左编辑右预览，中间可**拖拽**调宽；**双击分隔条回到 50/50** |
| 编辑 | `Ctrl+3` | 全宽 CodeMirror 6 |

编辑能力刻意克制：CodeMirror 6 + Markdown 语法模式，覆盖常用快捷键
（`Ctrl+B` 分栏、`Ctrl+S` 保存等），可开**自动保存**（默认开，停止输入 1.2s 后写盘）。

### 3.4 正文主题系统（最能体现产品气质的模块）

**12 款可选主题，每款是一整套文档视觉**（不是「换个背景色」）：
纸面、正文、标题、引用块、表格斑马纹、代码块底色、行内代码、以及 6 个语法着色位
**全部同属一个色系**，切换时不会出现「一半新配色、一半旧配色」的割裂。

| | 浅色（6） | 深色（6） |
|---|---|---|
| 素雅 | **素白** `#ffffff`、**宣纸** `#f9f5ec` | **夜阑** `#181b21`、**墨** `#101013` |
| 暖调 | **暖石** `#f6f1e7`、**麦穗** `#fbf7ec` | **琥珀** `#1c1713` |
| 冷调 | — | **青金** `#131822`、**涟漪** `#111a1c` |
| 柔彩 | **花瓣** `#fdf5f6`、**草木** `#f3f7f0` | **鼠尾草** `#161c18` |

中文命名是这个模块的灵魂：**宣纸、麦穗、琥珀、青金、鼠尾草、涟漪** ——
每个名字直接对应一种材质或自然物，用户不需要理解十六进制就能预期看到什么。

**设置面板里的主题卡片不是色块，而是真实排版缩略图**：用 Shadow DOM 局部注入该主题的
CSS 变量，渲染同一段真内容（标题「季度营收」+ 正文 + 强调 + 引用块）。
Shadow DOM 提供样式隔离，12 张卡片既不互相污染也不污染主文档。

附加机制：卡片支持 **star 星标收藏**（hover 才浮现，避免常驻视觉噪音），
收藏项单独成第一个页签；分类页签为 全部 / 浅色 / 深色 / 素雅 / 暖调 / 冷调 / 柔彩。

### 3.5 字体系统：为「一个汉字都不掉字形」不惜体积

这是本项目最「不妥协」的地方，也是**个人自用版**的自觉选择。

- **内置完整字符集**：全部中文字体都以完整字符集内置，**任何汉字都不会 fallback 到系统字体导致字形突变**。
- **符号补齐层（关键机制）**：实测所有开源中文字体，`✔ U+2714 / ✗ U+2717 / ✘ U+2718`
  与大部分上下标**只有更纱等宽齐备** —— 思源黑/宋都缺。
  本项目从更纱等宽子集化出一个 **2.8 KB 的「Eunice Symbol Gap」**，插在每条字体栈的第二位，
  于是兜底链变成：**装饰字体 → 符号补齐层 → 思源 SC → 系统符号 → emoji**，
  前三段全部随包分发，**不再依赖 Windows 专有字体**（此前离开 Windows 就是豆腐块）。
  该约束已固化为可断言指标：`python scripts/check-coverage.py --stacks` 对 10 条字体栈
  逐一校验并集无缺口，退出码 0 可进 CI。
- **西文只当装饰**：Inter / EB Garamond / JetBrains Mono 实测只有约 230 个码位，
  因此只能放在字体栈**前面**当装饰；浏览器**按单个字符回退**，
  于是「西文用 Inter + 中文用思源黑体」自动成立。
- **霞鹜文楷分片按需加载**：194 个 `unicode-range` 分片，运行时只用真正出现的那几片（约 100–250 KB）。
- **11 套字体预设**，分 7 类（全部 / 无衬线 / 衬线 / **圆体** / 楷体 / 等宽 / 系统）：

  | 预设 | 风格 | 说明 |
  |---|---|---|
  | 思源黑体 | 无衬线 | 三万码位全字符 · 默认 |
  | 思源宋体 | 衬线 | 长篇中文阅读 |
  | 霞鹜文楷 | 楷体 | 按需加载 194 片 |
  | Inter + 思源黑体 | 无衬线 | 西文/数字用 Inter |
  | Garamond + 思源宋体 | 衬线 | 西文衬线，适合引文 |
  | JetBrains Mono + 思源黑体 | 等宽 | 技术文档 |
  | **狮尾圆体** | 圆体 | 柔和不幼稚（45,217 码位） |
  | **霞鹜新致宋** | 衬线 | 老式衬线 · 书卷气（33,497 码位） |
  | **更纱等宽** | 等宽 | 等宽中文 · 码位最全（48,604 码位） |
  | **未来荧黑** | 无衬线 | 几何无衬线 · 偏现代（32,227 码位） |
  | 系统字体 | 系统 | 微软雅黑 · 零加载 |

  > 4 款扩充字体均为开源许可（OFL 1.1，霞鹜新致宋为 IPA Font License 1.0），
  > 许可证全文随仓库分发在 `src/fonts/licenses/`。

### 3.6 排版微调

设置抽屉里三个滑杆，实时生效（「边调边看」）：

| 项 | 范围 | 默认 | 说明文案 |
|---|---|---|---|
| 正文字号 | 12–24px | 16px | 「中文正文建议 16–18px」 |
| 行高 | 1.4–2.6 | 1.9 | 「中文行距要比英文宽，1.8–2.0 最舒适」 |
| 正文宽度 | 600–1600px | 900px | 「中文长段落建议不超过 900px，否则回行时眼睛容易串行」 |

默认值本身就是产品的态度宣言：**行高 1.9、行宽 900px** —— 按中文长文阅读调的，不是按英文排版的。

### 3.7 导出 PDF

走 WebView2 原生 `PrintToPdf`：**只弹一次「保存到哪」**，不经系统打印对话框。
排版与屏幕完全一致（同引擎、同 CSS），导出的文字**仍可选中、可搜索**。

纸面细节（`src/styles/print.css`）：

- 打印时**强制浅色主题**（深色打印大量吃墨）
- 标题 `break-after: avoid` 防孤行；表格 / 代码块 / 引用 / 图片 / 图表 `break-inside: avoid` 防拦腰截断
- 宽表格从横向滚动改为**自动换行**（纸面上没法横滚）
- 隐藏全部界面层与复制按钮、锚点 `#`、外链 `↗`
- `@page A4 / 18mm × 16mm`，正文 11.5pt / 行高 1.75
- 导出前等 `document.fonts.ready`（**上限 2.5s**）—— 否则分片加载的中文字体来不及，前几页会掉字形

### 3.8 Windows 系统集成

- **文件关联**：`.md .markdown .mdown .mkd .mdwn .mdtxt .mdtext .rmd .qmd` 九种扩展名
- **专属文件图标**：`.md` 在资源管理器里显示**文档卡图标**（`icons/file-markdown.ico`），
  而不是套用 exe 图标 —— 否则文件与应用长得一样，列表里分不出类型。
  该图标随包分发（`bundle.resources`），安装钩子写 `.md\DefaultIcon`，
  Rust 侧 `register_open_with` 在首次启动时同样写入（兜住被其他程序改回来的情况），
  两处都调用 `SHChangeNotify` 让资源管理器立即刷新，不必注销

  > ⚠️ **安装钩子的宏名是个坑**：Tauri v2 的 `installer.nsi` 只调用
  > `NSIS_HOOK_PREINSTALL` / `POSTINSTALL` / `PREUNINSTALL` / `POSTUNINSTALL`，
  > **不调用** `customInstall` / `customUnInstall`。
  > 本项目原先是按 `customInstall` 写的 —— 宏被 `!include` 进来了却从未
  > `!insertmacro`，于是**整段右键菜单与「打开方式」注册一直静默失效**；
  > 又因为宏不被展开，里面引用的未定义变量也不会报错，构建照样成功。
  > 已改为 `NSIS_HOOK_POSTINSTALL` / `POSTUNINSTALL` 并实测通过安装→卸载全流程。
  > 另外变量名是 `SHCTX`（Tauri 在 `.onInit` 里用 `SetContext` 设定），不是 `SHELLCTX`。
- **右键菜单**「使用 Eunice Reader 打开」由 NSIS 安装钩子注册，卸载时清理并
  `SHChangeNotify` 通知资源管理器刷新（否则要注销才消失）
- **「打开方式」列表**：首次启动用 `register_open_with` 补写 `HKCU`（免管理员权限）
- **直接拖文件进窗口**即可打开；拖入时全窗压一层薄雾 + 胶囊提示「松手即可打开」
  （刻意**不画虚线边框** —— 那一圈 dash 会在正文边缘凭空加一条线，比提示本身还抢眼）
- **编码**：UTF-8 优先并检测 BOM，解码失败依次回退 GB18030 → GBK → Big5；
  状态栏显示编码来源，**非 UTF-8 时标黄**；写入始终 UTF-8 无 BOM

### 3.9 安全与健壮性（设计上克制但完整）

- 内嵌 HTML 必须过 **DOMPurify** 才进 DOM
- Mermaid 走自己的 `securityLevel: 'strict'`，**不经过 DOMPurify**（否则它的 SVG 会被规则误伤）
- 前端**没有** fs 插件的任意路径访问权，文件读写全部走 Rust 命令（权限最小化）
- **启动文件传递刻意反过来做**：Rust 把路径存进 `Mutex<Option<String>>`，前端就绪后主动
  `take_startup_file()` 取走 —— 彻底消除「事件发得比监听器注册早 → 双击 .md 打开得到空白窗口」的时序竞争
- 窗口 `visible: false` 启动，**在 `finally` 里**才 `show_main_window()`；
  初始化任何一步抛错都会先把错误渲染到页面，而不是留一个永远黑屏

## 四、风格：一款「安静的工具」

> 以下结论均可回溯到 `src/styles/*.css`，完整取值表见 [design-system-extract.md](design-system-extract.md)。

### 4.1 三句话概括

1. **阅读优先，界面退后。** 灰阶界面 + 极低色彩信息量，把注意力让给文档。
2. **工具与内容分层。** 界面明暗（`data-theme`）和文档主题（`data-theme-doc`）是**两件独立的事**：
   界面壳可以是深色，文档纸面依旧是宣纸白。
3. **一个暖强调色 + 纸 + 墨。** 文档层的色彩单元永远是「纸面 + 墨色 + 一个同色系强调色」。

### 4.2 色彩：界面冷、文档暖

**界面层（工具）** 是中性灰 + 单一强调色。**刻意避开纯黑**——工具界面不该有纯黑，
纯黑会把「轻」的产品压沉；阴影与分隔线统一走 `--ink-rgb` 一支，不再散落十多处字面量：

| 令牌 | 浅色 | 深色 |
|---|---|---|
| 界面底（内容 / 工具 / 下沉） | `#ffffff` / `#f8f9fa` / `#eef0f2` | `#1c1f24` / `#22262c` / `#17191d` |
| 文字三级 | `#2c3138` / `#616a75` / `#8b949e` | `#e6e9ee` / `#9aa4b0` / `#79828e` |
| 强调色 | `#4f46e5` | `#7c73f0` |
| 分隔线 | `rgba(44,49,56,.10)` | `rgba(255,255,255,.09)` |
| 阴影基色 | `rgba(44,49,56,…)` | `rgba(10,12,15,…)` |

> 原先浅色最深字色是 `#1c1f23`、深色底是 `#101216`/`#14161a`，
> 均已在 2026-10-14 的改版中抬高为深灰。悬浮提示也从「深色药丸底」改为浅灰底 + 描边，
> 去掉了界面上最大的一片近黑。

**文档层（内容）** 是每主题各自的暖色：素白 `#8a5524`、宣纸 `#b04a30`、暖石 `#8d5031`、
花瓣 `#b8556e`、草木 `#4d7d45`、麦穗 `#96702a`；深色侧为夜阑 `#8fa8d8`、墨 `#b8b2a6`、
琥珀 `#d9a35c`、青金 `#7d9fd8`、鼠尾草 `#8fbfa0`、涟漪 `#78b8b4`。

> ⚠️ **美术侧最容易搞错的一点**：宣传物料里若画「产品强调色」，
> 用在**文档/纸面语境**上必须取**文档主题暖色**（如宣纸 `#b04a30`）；
> 界面紫 `#4f46e5` 只属于工具层（按钮、焦点圈、选中态），不要拿它去染纸张。

### 4.3 材质：毛玻璃，但要「看得出下面在滚什么」

顶栏、状态栏、设置抽屉、拖放层都用毛玻璃。三要素缺一不可：
**半透明底色 + 模糊 + 饱和度提升**，再加一条内侧高光边与投影把层次抬起来。

| 层 | 模糊 | 底色（浅 / 深） |
|---|---|---|
| 顶栏 / 状态栏（默认 normal 档） | `blur(20px) saturate(150%)` | `rgba(247,248,249,.62)` / `rgba(20,22,27,.68)` |
| 设置抽屉 | `blur(24px) saturate(160%)` | 面板 `rgba(247,248,249,.72)` / `rgba(20,22,27,.78)` |
| 拖放提示层 | `blur(5px) saturate(140%)` | 强调色 7% 淡染 |

三档强度可切换：**实色**（`blur: none`，给关掉系统透明效果的用户）/ **半透明**（默认）/ **强通透**（`blur(28px) saturate(165%)`）。

**关键在布局，不在属性**：顶栏/状态栏/侧栏是 `position:absolute` **叠在工作区之上**，
工作区占满整窗。若工作区只是 grid 里的一行（兄弟元素），毛玻璃什么也模糊不到 ——
必须让内容真的从玻璃层**下面滚过去**。

`--glass-tint` 兜底层：即使 `backdrop-filter` 没执行（软件渲染 / 系统关了透明效果），
文字下面仍有一层同色底衬，不会和文档糊在一起。底色不透明度的下限就是**对比度的下限**。

### 4.4 排版：一行行按中文调的

| 项 | 值 |
|---|---|
| 正文字号 / 行高 / 字距 | 16px / **1.9** / **0.02em** |
| 段落 | `text-align: justify` + `text-align-last: start`（两端对齐，但末行保持自然） |
| 标点挤压 | `text-spacing-trim: space-first`（古老浏览器回退 `text-autospace: normal`） |
| 标题 | 字重 **600**（不是 700）、`word-break: keep-all` 防「单字成行」、字距 0.01em |
| 列表缩进 | **2em**（比英文的 2ch 更合中文阅读习惯） |
| 行宽 | 900px 上限；正文两侧留白 40px，底部 45vh（让末段能滚到视线中部） |
| 链接 | 不用下划线，用 **25% 透明度的 1px 下边框**，悬停变实 —— 「不加看不清边界，纯下划线太吵」 |

字体栈形态：`'Eunice Inter', 'Eunice Sans SC', 'Segoe UI Symbol', 'Segoe UI Emoji', sans-serif`
（西文装饰在前，中文兜底在后，按**单个字符**逐级回退）。

### 4.5 形状与动效：克制

- **圆角只有三档**：`5px`（小）/ `8px`（中）/ `12px`（大，实际未被引用）；
  组件级另有 `6px`（分段按钮、行内代码、图片、提示块、复制按钮）、`4px`（kbd、编码徽标、主题色点）、`999px`（胶囊）
- **图标**：Lucide 1.56.0，`viewBox 0 0 24 24`，**线条被 CSS 从 2 收到 1.75**；
  颜色一律 `currentColor` 自动跟随主题；实际使用尺寸 44（空状态插画）/17（顶栏）/16/15/14/13/11px
- **动效**：0.1s–0.26s，全部 `ease`，唯一一条自定义曲线
  `cubic-bezier(0.32, 0.72, 0, 1)` 只用于抽屉滑动；tooltip 额外延迟 0.35s 防误触
- **滚动条**：11px 宽，透明轨道，滑块 `color-mix(fg 20%)` + 3px 透明边框内缩；悬停加深到 34%
- **层级**：工作区 0 / 顶栏·状态栏 20 / tooltip 60 / 抽屉遮罩 90 / 拖放层 95 / 抽屉 100

### 4.7 气质关键词（资产调性锚点）

安静 · 留白 · 纸质 · 墨感 · 克制 · 温暖 · 无彩界面 · 呼吸感 · 中文优先 · 材质感 · 层次分明 · 不炫技 · 工具感（而非「产品感」）

**要什么**：纸/墨/木/石/织物这类材质暗示；暖调低饱和色；大留白；细线条；
墨色或宣纸色的字；一两处暖强调色点睛。

**不要什么**：深色 IDE 面板；霓虹代码高亮；渐变mesh；玻璃拟物 3D 大色块；
紫蓝科技感主视觉；emoji 大杂烩；数码界面截图式的密集控件堆叠。
